# Trang Vu Portfolio — Build Plan

## Goal
Create a refined white-and-beige portfolio inspired by the attached editorial references, with Trang’s portrait and five clearly navigable content areas.

## Pages and content
- Build a polished home page with a slim navigation, introductory portrait section, and a visual overview of all five portfolio areas.
- Add dedicated pages for About, Work Projects, Education & Research, Personal Projects, and Self-Study.
- Use the supplied About copy exactly and the uploaded portrait as the main personal image.
- Organize Work Projects into Germany, Thailand, and Vietnam, each showing three large sample projects in one row.
- Add “See More” dialogs for every work project with Situation, Task, Action, and Results sections.
- Clearly present invented project names and details as editable sample content rather than personal claims.

## Visual direction
- Warm white, soft beige, charcoal, and restrained blue accents drawn from the portrait.
- Elegant editorial serif headings paired with a clean sans-serif body font.
- Airy full-width sections, thin rules, square-cornered imagery, and restrained transitions.
- Use original, cohesive project imagery rather than the reference screenshots themselves.

## Technical details
- Create shared site navigation and reusable editorial page/project components.
- Keep all five areas available as separate URLs with their own titles and social descriptions.
- Make project dialogs keyboard-accessible and easy to close.
- Ensure desktop and mobile layouts remain readable and balanced.
- Verify the live result for errors and visual layout after implementation.
